# League of Coders

Es una pequeña biblioteca de autores, en los cuales se les lista sus obras más famosas

## Estructura del proyecto

- `frontend/` - Aplicación Angular
- `backend/` - API REST con Spring Boot

## Requisitos

- Node.js y Angular CLI
- Java y Maven
- Base de datos (MySQL/PostgreSQL)

## Cómo ejecutar

### Frontend
```bash
cd frontend
npm install
ng serve
```

### Backend
```bash
cd backend
mvn spring-boot:run
```
